# 数字人Web管理系统

## 📋 项目简介

数字人Web管理系统是一个基于Gradio开发的Web界面，用于管理和操作视频生成项目中的数字人资源。该系统提供了直观的图形界面，简化了数字人的上传、配置和管理流程。

## ✨ 主要功能

### 🎭 数字人管理
- **列表展示**: 显示所有数字人的当前状态
- **分类视图**: 支持横屏、竖屏、小屏分类显示
- **详细信息**: 查看每个数字人的文件状态和配置信息
- **媒体预览**: 在线预览数字人图片和播放参考音频

### 📤 上传功能
- **单个上传**: 选择指定数字人进行上传
- **批量上传**: 一键上传所有本地数字人
- **进度反馈**: 实时显示上传状态和结果

### ➕ 创建功能
- **新数字人创建**: 上传照片和音频创建新数字人
- **文件管理**: 自动组织数字人目录结构
- **即时可用**: 创建后可直接进行上传

### ⚙️ 配置管理
- **配置查看**: 查看已上传数字人的配置信息
- **状态监控**: 通过配置文件判断上传状态
- **配置重置**: 删除配置文件重置上传状态

## 🚀 快速开始

### 环境要求
- Python 3.12+
- 项目依赖（已包含在pyproject.toml中）

### 安装和运行

1. **确保项目环境已准备**
   ```bash
   # 使用uv安装依赖
   uv sync
   ```

2. **启动数字人管理系统**
   ```bash
   # 使用快速启动脚本
   uv run python run-digital-human-manager.py

   # 或直接运行主程序
   uv run python digital-human-web-manager.py
   ```

3. **访问Web界面**
   - 在浏览器中打开: http://localhost:7860
   - 界面将自动显示当前数字人列表

## 🎯 使用指南

### 1. 查看数字人
- 主界面显示所有数字人的当前状态
- 通过标签页切换不同视图（全部/横屏/竖屏/小屏）
- 状态说明：
  - ✅ 已上传：数字人已成功上传到服务器
  - 🔶 未上传：数字人仅在本地存在

### 2. 上传数字人
- **单个上传**: 在下拉菜单中选择数字人，点击"上传选中数字人"
- **批量上传**: 点击"批量上传"按钮上传所有本地数字人
- 上传结果会显示在操作结果区域

### 3. 创建新数字人
1. 切换到"创建新数字人"标签页
2. 填写数字人名称
3. 上传必要的文件：
   - 横屏图片 (landscape.png)
   - 竖屏图片 (portrait.png)
   - 小屏图片 (short.png)
   - 参考音频 (reference.mp3)
4. 点击"创建数字人"按钮

### 4. 管理配置
- 在"配置信息"标签页查看数字人详细信息
- 预览数字人的图片和音频文件
- 查看配置文件内容
- 删除配置文件重置上传状态

## 🔧 技术实现

### 核心技术栈
- **前端框架**: Gradio 4.x
- **后端**: Python 3.12+
- **文件操作**: pathlib, shutil
- **进程调用**: subprocess
- **配置管理**: json, dotenv

### 架构设计
- **DigitalHumanManager**: 核心业务逻辑类
- **DigitalHumanWebInterface**: Web界面管理类
- **模块化设计**: 分离数据处理和界面展示
- **事件驱动**: 基于Gradio事件系统

### 关键功能实现
- **文件扫描**: 自动扫描characters目录获取数字人列表
- **状态检测**: 通过reference.json存在性判断上传状态
- **命令集成**: 调用main.py --upload实现上传功能
- **实时更新**: 操作后自动刷新界面状态

## 📝 注意事项

### 文件要求
确保每个数字人目录包含以下文件：
- `landscape.png` - 横屏图片 (必需)
- `portrait.png` - 竖屏图片 (必需)
- `short.png` - 小屏图片 (必需)
- `reference.mp3` - 参考音频 (必需)

### 配置文件
- `reference.json` - 上传成功后自动生成
- 包含服务器返回的各种ID信息
- 删除此文件可重置数字人为未上传状态

### 网络要求
- 上传功能需要网络连接到RunningHub服务
- 确保API密钥已正确配置在.env文件中
- 上传过程可能需要几分钟，请耐心等待

## 🚨 故障排除

### 常见问题

1. **界面无法打开**
   - 检查端口7860是否被占用
   - 确保所有依赖已正确安装

2. **数字人列表为空**
   - 确认characters目录存在
   - 检查数字人文件夹结构是否正确

3. **上传失败**
   - 检查网络连接
   - 确认API密钥配置正确
   - 查看操作结果区域的错误信息

4. **文件预览失败**
   - 确认文件路径正确
   - 检查文件格式是否支持

### 日志查看
程序日志会输出到控制台，包含详细的操作信息和错误提示。
