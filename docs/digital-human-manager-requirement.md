# 数字人管理系统 - 项目需求书

## 📋 项目概述

### 项目背景
为了更好地管理视频生成项目中的数字人资源，需要开发一个基于Gradio的Web前端界面，提供直观、易用的数字人管理功能。

### 项目目标
- 提供友好的Web界面管理数字人
- 简化数字人上传、配置和选择流程
- 提升用户体验和操作效率

## 🎯 功能需求

### 1. 数字人资源管理
- [ ] **数字人列表展示**：显示characters目录下所有数字人
- [ ] **分类显示**：按照横屏（landscape）、竖屏（portrait）、小屏（short）分类显示
- [ ] **数字人详情**：显示每个数字人的图片、参考音频、配置ID信息
- [ ] **状态监控**：通过JSON文件存在性判断数字人是否正常上传
- [ ] **可视化预览**：展示数字人图片和音频播放功能

### 2. 数字人上传功能
- [ ] **单个上传**：支持选择并上传单个数字人
- [ ] **批量上传**：一键上传所有数字人
- [ ] **上传进度**：实时显示上传进度和状态
- [ ] **结果反馈**：上传成功/失败的详细反馈信息
- [ ] **命令行集成**：通过调用main.py --upload实现上传功能

### 3. 新数字人创建功能
- [ ] **照片上传**：支持上传数字人照片
- [ ] **音频上传**：支持上传参考音频文件
- [ ] **命名功能**：为新数字人自定义名称
- [ ] **自动配置**：自动生成数字人配置文件和目录结构
- [ ] **即时上传**：创建完成后可直接上传到服务

### 4. 数字人配置管理
- [ ] **配置信息展示**：显示数字人的JSON配置ID和参数
- [ ] **配置编辑**：支持修改数字人配置信息
- [ ] **文件管理**：管理数字人的图片、音频等资源文件
- [ ] **状态同步**：实时同步上传状态和配置信息

### 5. 分类视图管理
- [ ] **横屏视图**：专门管理landscape类型数字人
- [ ] **竖屏视图**：专门管理portrait类型数字人
- [ ] **小屏视图**：专门管理short类型数字人
- [ ] **全部视图**：统一管理所有类型数字人
- [ ] **视图切换**：支持在不同分类视图间快速切换

### 视觉设计要求

#### 状态指示设计
- ✅ **已上传**：绿色标识，JSON文件存在
- ❌ **未上传**：红色标识，配置文件缺失
- ⏳ **上传中**：黄色标识，上传进行中
- 🔄 **处理中**：蓝色标识，后台处理中

#### 分类视图设计
- **横屏视图**：卡片采用横向布局，适配landscape类型
- **竖屏视图**：卡片采用竖向布局，适配portrait类型
- **小屏视图**：紧凑型卡片，适配short类型
- **全部视图**：混合布局，显示所有类型

### 交互设计
- **拖拽上传**：支持照片和音频文件拖拽上传
- **实时状态更新**：上传进度和状态实时刷新
- **音频预览**：点击播放按钮预览参考音频
- **图片放大**：点击数字人图片查看大图
- **快速操作**：悬停显示快捷操作按钮
- **批量操作**：支持多选进行批量上传/删除

## 🔧 技术需求

### 技术栈
- **前端框架**: Gradio 4.x
- **后端**: Python 3.12+ (集成现有项目)
- **文件存储**: 本地文件系统 (characters目录)
- **API集成**: 调用main.py命令行工具
- **UI组件**: Gradio原生组件 + HTML/CSS定制

### 核心功能实现
- **目录扫描**: 扫描characters目录获取数字人列表
- **文件解析**: 读取config.json获取配置信息
- **命令调用**: 通过subprocess调用main.py --upload
- **文件上传**: Gradio文件上传组件处理照片和音频
- **界面刷新**: 定期刷新数字人状态和列表

### 界面组件规划
```python
# 主要Gradio组件
gradio.Interface()           # 主界面
gradio.Gallery()            # 数字人图片展示
gradio.Audio()              # 音频播放组件
gradio.File()               # 文件上传组件
gradio.Button()             # 操作按钮
gradio.Dropdown()           # 类型选择下拉框
gradio.Textbox()            # 名称输入框
gradio.HTML()               # 自定义HTML展示
gradio.Tabs()               # 分类标签页
```

### 技术实现要点
- **文件监听**: 监听characters目录变化
- **JSON解析**: 解析config.json获取上传状态
- **命令集成**: 封装main.py命令行调用
- **错误处理**: 优雅处理文件不存在、命令执行失败等情况
- **响应式布局**: 适配不同屏幕尺寸

### 性能要求
- 页面加载时间 < 3秒
- 数字人列表刷新 < 1秒
- 文件上传支持常见的图片和音频格式
- 界面响应流畅，无卡顿

### 兼容性
- 支持主流浏览器（Chrome, Firefox, Safari, Edge）
- 本地部署，无需外网访问
- 兼容现有项目的uv环境管理

## 📋 核心需求总结

### 必须实现的核心功能
1. **数字人列表展示**：扫描characters目录，按分类显示
2. **基本信息显示**：图片、音频、配置ID展示

### 简化设计原则
- 不进行复杂的状态管理和进度跟踪
- 通过文件存在性简单判断上传状态
- 直接调用现有命令行工具，不重复实现API逻辑
- 保持界面简洁，专注核心功能

### 技术实现重点
- Gradio Web界面开发
- 文件系统操作和JSON解析
- subprocess命令行调用
- 响应式布局和用户交互
